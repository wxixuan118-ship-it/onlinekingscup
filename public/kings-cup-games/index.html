What Are the Kings Cup Games?

Kings Cup is a drinking card game for 3–10 players built around one shuffled 52-card deck spread face down in a ring around a cup. Every rank maps to an action, the first three Kings pour into the cup, and the fourth King drinks it. That core loop is the same in every version; what changes is the name on the box, a few card meanings and the format of the session.

Because the game has no official publisher, the Kings Cup games family is really one game with many identities. Wikipedia catalogues the game and its aliases under King game. The Kings Cup rules page explains the default loop; this page maps the family tree so you can jump to the version you want.

Kings Cup Games by Name

The same game travels under several names depending on where you grew up. They all describe the same draw-and-follow loop; only a few house rules differ.

Kings Cup

The most common name in North America. The deck is spread in a ring around a center cup, and the game is named after the cup rather than the ring. The Kings Cup rules page is the full reference for this version.

Ring of Fire game

The usual name in the UK, Ireland and Australia. Named after the circle of cards, and tables that use this name often enforce a broken-ring penalty. The Ring of Fire rules page covers this version in full.

Circle of Death game

Common in the US college scene. Same core loop; the name emphasises that drawing the wrong card can end your night. Most Circle of Death tables use the same card meanings as Kings Cup.

Waterfall and King’s Game

Regional names that turn up in parts of Europe and on college campuses. Waterfall is sometimes used to refer to the whole game because the Ace rule is the most memorable; King’s Game is a direct translation of several European names.

Kings Cup Games by Format

Beyond the name, this family of games includes different formats for different groups and settings. All keep the same card loop; they change the length, the player count or whether alcohol is involved.

Short game

Half a deck or a 20-minute timer, with the last King before time triggering the finale. Best for pre-drinks or when a table wants a few rounds rather than a full session.

Large group game

For ten or more players, split into teams and cap word games at five seconds so turns keep moving. Nomination cards go to a team instead of an individual.

Two-player game

Replace the group-dependent cards (Floor, Heaven, Mate) with shared prompts. The Kings Cup for two guide has the full swap list.

Non-drinking game

Swap every drink for a penalty point, water, a trivia question or a dare. The without alcohol guide has the complete substitution list, and the variations page lists every format.

Related Party Games

The same crowd that plays Kings Cup often plays other party games before or after. These are the ones that pair best because they use similar skills — reactions, memory and the ability to keep a straight face.

Beer Pong game

The classic before-and-after game. Two teams throw ping-pong balls into cups of beer; a sunk cup means the other team drinks. The Beer Pong page has the rules, setup and winning techniques.

Go Fish game

A lighter card game for when the table wants to slow down. Ask another player for a rank, collect sets of four, and the player with the most sets wins. The Go Fish page covers the rules.

Kings Cup Games FAQ

What games are in the Kings Cup family?

The main game is a drinking card game where players draw from a ring of face-down cards around a center cup. It travels under names including Ring of Fire and Circle of Death, and has many house-rule variations. Related party games include Beer Pong and Go Fish.

Is Ring of Fire the same game?

Yes. Ring of Fire is the same game under a different name, used mostly in the UK, Ireland and Australia. The core loop is identical; only the broken-ring penalty and a few card swaps tend to differ.

Which version is best for beginners?

The standard game with the default card list is the best place to start. Learn Ace, 2, 3 and the three face cards first, then look the rest up as they come. Variations like Jack as Make a Rule keep it fresh once the table is comfortable.
